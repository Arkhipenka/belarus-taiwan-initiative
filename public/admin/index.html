Belarus–Taiwan & East Asia Platform

Материалы — через редактор.

Статьи, новости, мероприятия и тексты главной доступны в Pages CMS. Изменения сохраняются в GitHub и запускают автоматическую публикацию сайта.

Открыть Pages CMS ↗
Первое подключение
  1. Войдите в Pages CMS через свой GitHub.
  2. Если появится запрос установки GitHub App, предоставьте доступ только к Arkhipenka/belarus-taiwan-initiative.
  3. Откройте репозиторий и ветку main. Конфигурация редактора уже подготовлена.

Как опубликовать материал

  1. Выберите язык и раздел: «Статьи», «Новости» или «Мероприятия».
  2. Заполните заголовок, дату и адрес латиницей. Добавьте обложку и текст через визуальный редактор.
  3. Для черновика оставьте «Опубликовано» выключенным. Для публикации включите его и сохраните.
  4. Дождитесь завершения автоматической сборки. Переводы редактируются отдельно; CMS не переводит текст автоматически.

Существующие тексты уже перенесены. Названия и описания блоков главной находятся в разделе «Главная» каждого языка.
